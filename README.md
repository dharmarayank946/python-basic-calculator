
# Basic Calculator

## Project Description
A simple calculator developed using Python functions.
It performs basic arithmetic operations through a
menu-driven interface.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
- Invalid input handling
- Menu repeats until the user exits

## Technologies Used
- Python 3
- VS Code

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python calculator.py`

## Learning Outcomes
- Functions
- Variables and data types
- User input and output
- Conditional statements
- Loops
- Exception handling
